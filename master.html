01
⬡ Phase One — HTML

Structure & Markup

HTML is the skeleton of everything on the web. You'll learn to structure content meaningfully before adding any style or behavior.

3–4 wks ~1–2 hrs/day
Week 01
Introduction to HTML & Document Structure
  • What is HTML and how browsers work
  • HTML document anatomy (DOCTYPE, html, head, body)
  • Headings h1–h6 and paragraphs
  • Line breaks and horizontal rules
  • HTML comments
  • Character entities (&amp;, &lt;, &gt;)
  • Viewing source code in a browser
  • Setting up VS Code for HTML
🛠
Project
Personal bio page — plain HTML, no styling. Just structure.
Week 02
Links, Images & Lists
  • Anchor tags and href attributes
  • Absolute vs relative URLs
  • Opening links in new tabs (target="_blank")
  • Image tags, src, alt text, width/height
  • Ordered lists (ol) and unordered lists (ul)
  • Nested lists
  • Description lists (dl, dt, dd)
  • Inline vs block elements
🛠
Project
Recipe page with ingredients list, steps, and a food image
Week 03
Tables, Forms & Semantic HTML
  • Table structure (table, tr, th, td)
  • Table spanning (colspan, rowspan)
  • Form elements: input, textarea, select, button
  • Input types: text, email, password, number, checkbox, radio
  • Form labels and accessibility
  • Semantic tags: header, nav, main, section, article, aside, footer
  • Why semantics matter for SEO and accessibility
  • div and span as non-semantic containers
🛠
Project
Multi-page website: Home, About, Contact form — fully semantic HTML
02
⬡ Phase Two — CSS

Visual Design & Layout

CSS transforms raw HTML into beautiful, responsive interfaces. This phase is where creativity meets code — you'll learn to build layouts that work on any screen size.

4–5 wks ~1–2 hrs/day
Week 04
CSS Fundamentals & The Box Model
  • How to link CSS to HTML (inline, internal, external)
  • CSS selectors: element, class, ID, universal
  • Specificity and the cascade
  • Colors: named, hex, rgb, hsl
  • The box model: content, padding, border, margin
  • box-sizing: border-box
  • Width, height, min/max variants
  • Display: block, inline, inline-block, none
🛠
Project
Style last week's multi-page site with colors, spacing, and typography
Week 05
Typography, Backgrounds & Pseudo-classes
  • Font properties: family, size, weight, style, line-height
  • Google Fonts integration
  • Text alignment, decoration, transform
  • Background: color, image, size, position, repeat
  • Gradients: linear and radial
  • Pseudo-classes: :hover, :focus, :nth-child, :first-child
  • Pseudo-elements: ::before, ::after
  • CSS custom properties (variables)
🛠
Project
Styled card component with hover effects and gradient backgrounds
Week 06
Flexbox — Modern Layout System
  • Flex container vs flex items
  • flex-direction: row and column
  • justify-content: space-between, center, etc.
  • align-items and align-self
  • flex-wrap and flex-grow/shrink/basis
  • gap property
  • Centering elements perfectly with flexbox
  • Building navigation bars with flexbox
🛠
Project
Responsive navigation bar + product card grid using flexbox only
Week 07
CSS Grid & Responsive Design
  • Grid container and grid items
  • grid-template-columns and rows
  • fr units and repeat()
  • Grid gap, column-span, row-span
  • When to use Grid vs Flexbox
  • Media queries (@media)
  • Breakpoints: mobile, tablet, desktop
  • Mobile-first design philosophy
  • Viewport meta tag
🛠
Project
Fully responsive portfolio/landing page — desktop + mobile layouts
Week 08
CSS Transitions, Animations & Positioning
  • Position: static, relative, absolute, fixed, sticky
  • z-index and stacking context
  • CSS transitions (transition property)
  • @keyframes and animation property
  • Transform: translate, rotate, scale, skew
  • Box-shadow and text-shadow
  • Border-radius and clip-path basics
  • Overflow: hidden, scroll, auto
🛠
Project
Animated landing page with scroll effects and hover interactions
03
⬡ Phase Three — JavaScript

Programming & Logic

JavaScript is the engine of the web — and the language you'll use for everything: websites, web apps, and React Native mobile apps. This is the most important and longest phase.

8–10 wks ~1–2 hrs/day
Week 09
JavaScript Basics — Variables & Data Types
  • What JavaScript is and where it runs
  • var, let, const — differences and when to use each
  • Data types: string, number, boolean, null, undefined
  • typeof operator
  • String methods: length, toUpperCase, slice, includes, split
  • Number methods and Math object
  • Template literals (backtick strings)
  • console.log() for debugging
🛠
Project
Console-based age calculator and string formatter
Week 10
Operators, Conditionals & Loops
  • Arithmetic, comparison, and logical operators
  • Truthy and falsy values
  • if, else if, else statements
  • Ternary operator
  • Switch statements
  • for loops and while loops
  • break and continue
  • Nested loops
🛠
Project
FizzBuzz + number guessing game in the console
Week 11
Functions
  • Function declarations vs expressions
  • Arrow functions (=>)
  • Parameters and arguments
  • Return values
  • Default parameters
  • Scope: global vs local vs block
  • Closures (introduction)
  • Higher-order functions (passing functions as arguments)
🛠
Project
Calculator app with reusable functions for each operation
Week 12
Arrays & Array Methods
  • Creating and accessing arrays
  • push, pop, shift, unshift
  • splice, slice, concat, join
  • forEach — iterate over arrays
  • map — transform arrays
  • filter — filter arrays
  • find and findIndex
  • reduce — powerful aggregation
  • Spread operator with arrays
🛠
Project
Shopping cart logic: add, remove, filter, and total items
Week 13
Objects & Object-Oriented Thinking
  • Object literals: keys and values
  • Accessing properties: dot vs bracket notation
  • Nested objects
  • Object methods (functions inside objects)
  • Destructuring objects and arrays
  • Spread operator with objects
  • Object.keys(), Object.values(), Object.entries()
  • Introduction to classes and constructor functions
🛠
Project
Student grade tracker using objects and arrays
Week 14
The DOM — Making Pages Interactive
  • What the DOM is
  • Selecting elements: getElementById, querySelector, querySelectorAll
  • Changing text and HTML content
  • Changing styles dynamically
  • Adding and removing CSS classes
  • Creating and appending elements
  • Removing elements
  • Event listeners: click, input, submit, keydown
  • Event delegation
🛠
Project
Interactive to-do list — add, complete, delete tasks. Fully DOM-based.
Week 15
Asynchronous JavaScript & APIs
  • Synchronous vs asynchronous code
  • setTimeout and setInterval
  • Callbacks and callback hell
  • Promises: .then() and .catch()
  • async/await syntax
  • try/catch for error handling
  • What an API is
  • fetch() — making HTTP requests
  • JSON: parsing and stringifying
🛠
Project
Weather app using a free public API (OpenWeatherMap)
Week 16
ES6+ Modern JavaScript & Local Storage
  • Modules: import and export
  • Optional chaining (?.)
  • Nullish coalescing (??)
  • localStorage and sessionStorage
  • Saving and loading data from storage
  • JSON with localStorage
  • Error types and custom errors
  • Regular expressions (basics)

To-do list upgraded — data persists after page refresh using localStorage

⬡ Phase Four — React

Component-Based UI

React teaches you to think in components — reusable building blocks. Mastering React makes the transition to React Native feel natural and fast.

6–8 wks ~1–2 hrs/day
Week 17
React Fundamentals — Components & JSX
  • What React is and why it exists
  • Setting up with Vite (recommended over Create React App)
  • JSX — writing HTML inside JavaScript
  • Functional components
  • Rendering components
  • Props — passing data to components
  • Children prop
  • Component composition
🛠
Project
Profile card component with reusable sub-components
Week 18
State Management with Hooks
  • What state is and why it matters
  • useState hook — reading and updating state
  • Re-rendering and how React updates the DOM
  • Handling events in React (onClick, onChange)
  • Controlled inputs and forms
  • Conditional rendering (&&, ternary)

  • Lifting state up
🛠
Project
React to-do list with add, delete, and toggle complete
Week 19
useEffect & Fetching Data
  • useEffect hook — side effects in React
  • Dependency array: [], [value], no array
  • Fetching data from APIs with useEffect
  • Loading and error states
  • Cleanup functions
  • Custom hooks (introduction)
  • useRef hook basics

Project
Movie/show search app using a public API (TMDB or OMDB)
Week 20
React Router & Multi-Page Apps
  • Installing React Router v6
  • BrowserRouter, Routes, Route components
  • Link and NavLink for navigation
  • useNavigate — programmatic navigation
  • useParams — dynamic route parameters
  • Nested routes
  • 404 Not Found page
  • Protected routes (basics)
🛠
Project
Multi-page blog with home, post list, and individual post pages

  • useContext hook — sharing state across components
  • useReducer hook — complex state logic
  • Context + useReducer as a mini Redux
  • Introduction to Zustand (lightweight state manager)
  • React Query / TanStack Query for server state

  • Code splitting with React.lazy

Capstone Project
Full e-commerce UI: product listing, cart, checkout flow with context state

⬡ Phase Five — React Native

Cross-Platform Mobile Apps

This is where everything converges. React Native uses the same JavaScript and React knowledge you've built — just with mobile-specific components and APIs. Android and iOS from one codebase.

6–8 wks ~1–2 hrs/day

React Native Setup & Core Concepts
  • Expo vs React Native CLI — choosing the right setup
  • Setting up Expo Go on your Android phone
  • Project structure overview
  • Core components: View, Text, Image, ScrollView
  • StyleSheet API (CSS-like but for mobile)
  • Flexbox in React Native (default layout system)
  • Platform-specific code (Platform.OS)
  • Hot reload and fast refresh

Week 24
User Input, Buttons & Touchables

  • Button, TouchableOpacity, TouchableHighlight
  • Pressable component (modern approach)
  • Handling touch events

Navigation with React Navigation

// Tips for Success

⏱
Consistency Over Intensity

1–2 hours every day beats 10 hours on a weekend. Your brain consolidates knowledge during sleep — daily practice is how programming actually sticks.

🏗
Build, Don't Just Watch

Every tutorial should end with you building something extra on your own. The moment you type code without copying is the moment real learning happens.

🐛
Embrace Bugs

Debugging is not a sign of failure — it's the actual job. Every bug you solve independently makes you a better developer than any tutorial could.

📁
Use GitHub from Day One

Create a GitHub account and push every project you build. This becomes your portfolio and proves your skills to future employers or clients.

🚫
Avoid Tutorial Hell

Don't watch 20 tutorials before building. Watch one, then build. Then watch the next one. Consuming content is not the same as learning.

🤝
Join a Community

Find developer communities on Twitter/X, Discord, or local dev groups. Asking questions and helping others accelerates growth faster than going solo.
