# 🚀 React Full Stack Roadmap

I built a visual roadmap of my journey to becoming a full stack React developer.
Join me on the journey — contributions and shared experiences are very welcome.

Learning programming can be a real challenge. The resources are out there without 
a doubt, but as someone who recently embarked on this journey myself, I found that 
the vast amount of information can be overwhelming at first.

I have therefore decided to document my steps so that others can follow and avoid 
unnecessary clutter in this diverse field of programming and web development.

## What's Inside
- Complete scheme of work (28+ weeks)
- Week by week topics and projects
- Curated free and paid resources
